# Træningsprogrammer

Mine egne træningsprogrammer som statiske sider, hostet via GitHub Pages.

- `index.html` — forside med oversigt over programmer
- `programmer/` — ét program pr. HTML-fil

## Tilføj et nyt program

1. Læg en ny `programmer/<navn>.html` (kopiér evt. et eksisterende som skabelon).
2. Tilføj et `<a class="card">`-kort i `index.html`, der peger på den.
